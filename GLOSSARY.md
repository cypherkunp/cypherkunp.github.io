# Glossary

**Pinned Project**: A repository chosen on the GitHub profile to be featured. The site shows exactly these, in the order GitHub returns them; it never picks projects itself.

**Project Override**: Hand-written text that replaces a Pinned Project's GitHub description on the site. Optional; without one, the GitHub description is shown, or nothing.

**Contribution**: One unit of activity as GitHub counts it (commits, pull requests, issues, reviews) on a given day.

**Contribution Timeline**: The single continuous grid of every day's Contributions, from the first contribution year to today. It opens on the present and is scrolled backwards through time; it is not split into separate per-year calendars.

**Snapshot**: The copy of GitHub data the site is built from, taken at a point in time. The page states when the Snapshot was taken.
